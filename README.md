# Laundry Wallah

A simple static website for a laundry service that offers convenient and professional cleaning solutions for everyday garments and specialty items.

## Overview

Laundry Wallah is a frontend landing page designed to showcase a laundry business and allow customers to quickly understand the services offered, pricing, and contact information. The page includes a friendly service overview, a price list, and a basic booking form.

## Features

- Clean and simple landing page layout
- Service highlights for laundry and garment care
- Pricing table for selected services
- Booking form for customer inquiries
- Contact information and support email
- Responsive layout for browser viewing

1. Open the project folder.
2. Double-click on `index.html` in your file explorer, or
3. Open it in a browser using VS Code Live Server or any local web server.
